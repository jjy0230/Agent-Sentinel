双通道毫秒级架构 (Dual-Path Architecture)

将 85% 确定性指令交由 L1 纳秒级通道瞬间放行，疑难动态命令交由 L2 Nokia AnyJev 单次前向 Logits 审查。

⚡ L1 确定性纳秒级过滤通道 (< 0.05ms)

基于前缀树 (Trie) 与预编译正则。对已知的日常安全操作（git status, ls, pwd, cargo check, ps aux | grep 等）以及灾难级黑名单（rm -rf /, :(){ :|:& };:）在 0.01ms 内瞬时完成裁决，绝大部分指令无需唤醒模型。

• git status ➔ ALLOW (0.012 ms)
• rm -rf / ➔ BLOCK (0.006 ms)
🧠 L2 AnyJev 单次前向校准内核 (< 25ms)

基于 Nokia Applied Research 的 AnyJev 机制。跳过极其耗时的自回归 Token 生成，仅提取单次 Prefill 结尾的未归一化 Logits，并经由离线先验偏移矩阵去偏，输出可信概率分布。

• P(ALLOW) > 0.90 ➔ 瞬间无感放行
• P(BLOCK) >= 0.10 ➔ 安全熔断报错
